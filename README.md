# 🛒 TechStore — Loja Virtual de Eletrônicos

## 📌 Sobre o projeto

A **TechStore** é um projeto de loja virtual desenvolvido como atividade acadêmica, com o objetivo de praticar os conhecimentos de desenvolvimento web utilizando HTML, CSS e JavaScript.

O site apresenta uma loja de produtos tecnológicos, com páginas organizadas para facilitar a navegação e a visualização dos produtos.

## 🚀 Funcionalidades

- 🏠 **Página inicial:** apresentação da loja e acesso às categorias.
- 📱 **Celulares:** página dedicada a smartphones.
- 💻 **Computadores:** produtos da categoria de informática.
- 🎮 **Games:** jogos digitais e conteúdos relacionados a games.
- 🎧 **Acessórios:** produtos complementares de tecnologia.
- 🔥 **Promoções:** página dedicada às ofertas.
- 🛒 **Carrinho:** área para visualizar e gerenciar os produtos selecionados.
- 👤 **Minha conta:** área relacionada à conta do usuário.
- ℹ️ **Sobre nós:** informações sobre a loja.
- 🔐 **Login:** página de acesso do usuário.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação das páginas.
- **CSS3:** estilização, cores e organização visual.
- **JavaScript:** implementação de interações e funcionalidades.

## ▶️ Como executar

1. Baixe ou clone este repositório.
2. Extraia os arquivos, caso tenha baixado o projeto compactado.
3. Abra a pasta do projeto no Visual Studio Code ou em outro editor.
4. Execute o arquivo `home.html` em um navegador.
5. Navegue pelas páginas utilizando o menu do site.

## 🎯 Objetivo acadêmico

Este projeto tem como finalidade colocar em prática os conhecimentos adquiridos durante os estudos de Análise e Desenvolvimento de Sistemas, especialmente na criação de páginas web, estilização com CSS, navegação entre páginas e utilização de JavaScript.

## 👨‍💻 Considerações finais

O desenvolvimento da TechStore representa uma oportunidade de aprender, praticar e aprimorar habilidades de programação web, além de compreender melhor a organização de um projeto com várias páginas e arquivos.
